# AquaLoop AI 💧
### Every Drop Has Another Purpose.

AquaLoop AI is a web-based project that explores how household water from air conditioners (ACs), RO purifiers, and washing machines can be reused responsibly for suitable non-drinking purposes.

## Features
- Water reuse assessment
- Water usage tracking
- Household water audit
- Safety guidelines and checklists
- Educational resources
- Water savings and cost estimation

## Tech Stack
- HTML
- CSS
- JavaScript

## Live Website
https://janasruthimylsamy.github.io/aqualoop/

## Goal
To raise awareness about household water reuse, reduce unnecessary water wastage, and encourage responsible water management.

## Safety Note
Water reuse depends on the source, possible contamination, and intended use. This project provides educational guidance and does not certify water safety or replace appropriate testing.
